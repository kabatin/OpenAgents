# knowledge — エージェントに覚えさせておく前提知識

会社の基本情報や、チームの決まりごとのように
**会話ログを検索しても出てこないが、答えるのに必要な前提**を置く場所です。

`personas/` が「どう話すか」なら、ここは「何を知っているか」です。

## 使い方

テンプレートをコピーして中身を書き換え、`config.json` の
`persona_files` に足してください（上から順に連結されて渡ります）。

```jsonc
"persona_files": [
  "../personas/agent1.md",
  "../knowledge/company.md"
]
```

## 同梱のテンプレート

| ファイル | 中身 |
|---|---|
| `company.example.md` | 会社・チームの基本情報 |
| `user.example.md` | 主に話す相手（あなた）のこと |

## 書くときのコツ

- **短く保つ**。ここに書いたものは毎回すべてAIに渡されます。長いほど遅く・高くなり、
  かつ指示が薄まります。A4で1〜2枚が上限の目安です
- **変わりにくいことだけ書く**。進行中の案件や今週の予定は書かないでください。
  それらは会話ログから検索されるので、二重に持つと古い方が答えに混ざります
- **一覧より文章**。「Aの担当はB」のような対応関係は表で、背景や方針は文章で

## 注意

`*.example.md` 以外のファイルは Git の追跡対象外です（`.gitignore`）。
**会社の非公開情報や個人情報をここに書いても、リポジトリには入りません。**
ただし、AIに渡る＝設定したLLMのサービスに送られるという点は変わらないので、
そこは各サービスの規約を確認したうえで判断してください。
