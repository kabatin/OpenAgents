## LINE 特有の注意

### Webhook 方式なので、外から届くURLが要る

LINE Messaging API は**LINE側からあなたのサーバーへHTTPSで通知する**方式です。
このプロジェクトの前提（自宅や社内のPCで動かす）とは相性が悪く、
実装するなら次のどれかが必要になります。

- Cloudflare Tunnel / ngrok などでトンネルを張る
- 小さな中継サーバーを別途立てる

**ポートを直接インターネットへ開けるのは避けてください**（設定ファイルに
Botトークンが入っています）。

### 応答の制約

- **リプライトークンは1回・約1分だけ有効**。LLMの生成に時間がかかるので、
  受信したらすぐ「考え中」を返し、生成後は Push メッセージで送る二段構えが要ります
- Push メッセージは無料枠に**送信数の上限**があります。観察ループのような
  「自発的に話しかける」機能は、そのまま有効にすると上限を使い切ります。
  既定でオフにする実装にしてください
