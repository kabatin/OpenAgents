# personas — エージェントの性格

エージェントの「人物像」と「話し方」を書いた Markdown ファイルを置く場所です。
ここに書いた内容は、回答を作るときに毎回そのままAIへ渡されます。

## 使い方

**ダッシュボードから選ぶのが一番簡単です**（`python start.py` → 性格を選ぶ）。
画面でテンプレートを選んで名前を入れると、このフォルダに
`<エージェントID>.md` が作られ、config.json の `persona_files` に登録されます。

手で作る場合も同じです。テンプレートをコピーして、`{{AGENT_NAME}}` などの
差し込み語を実際の値に置き換えてください。

```bash
cp personas/assistant.template.md personas/agent1.md
```

## 同梱のテンプレート

| ファイル | どんな性格か |
|---|---|
| `assistant.template.md` | 丁寧なアシスタント。敬語で落ち着いている。**最初の1体におすすめ** |
| `energetic.template.md` | 元気な後輩。フランクで距離が近い |
| `analyst.template.md`   | 寡黙な分析役。事実と根拠だけを短く返す |

## 書くときのコツ

- **短く保つ**。長い設定文は指示を薄めます。A4半分くらいが目安
- **禁止事項を書く**。「〜する」より「〜しない」の方がよく効きます
- **返信の長さを必ず指定する**。書かないと毎回長文になります
- 口調の指定は具体例で書く（「フランクに」より「語尾は〜っす」）

## 注意

`*.template.md` 以外のファイルは Git の追跡対象外です（`.gitignore`）。
自分用の性格ファイルが誤って公開されないようにしてあります。

会社情報や個人情報のような「知識」は、性格ではなく `knowledge/` に置いてください。
