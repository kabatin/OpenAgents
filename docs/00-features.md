# 機能一覧

このシステムに入っている機能の全カタログです。
**ほとんどはダッシュボードのトグル1つでON/OFFできます。**

凡例:
- 🟢 = 既定でON
- ⚪ = 既定でOFF（画面から有効化）
- 🌗 = シャドー対応 — 有効にしても最初は**投稿せず記録だけ**する試運転モードで動かせます

---

## 聞けば答える（会話）

ホームチャンネルの発言や `@名前` の呼びかけに答える、基本の能力です。

| 機能 | 説明 |
|---|---|
| 🟢 過去ログ検索回答 | 全会話をSQLiteに記録し、質問されると**検索してから**引用リンク付きで答える。エージェント間で記憶は共有 |
| 🟢 会話の文脈理解 | 直前の会話を読み、「それ」「あの件」の指す先を補って答える |
| ⚪ 名前呼び応答 | @メンションが無くても「〇〇、これ見て」と呼び名で呼ばれた発言に応答（既定オフ＋シャドー）。他のエージェントの名指し・他の自室・観察から外したチャンネルでは出ない |
| 🟢 リンク/ID参照 | メッセージリンクや素のIDを貼ると、その投稿の中身を読んで踏まえる。**リプライした投稿も同じ参照として先頭に入る**ので、通知や長文に返信して「これ対応して」と頼める |
| 🟢 リマインダー | 「明日9時に◯◯を知らせて」の自然文で登録。毎日・毎週・毎月末の繰り返し、チャンネル宛・ロール宛も可 |
| 🟢 YouTube要約 | URLが貼られたら字幕から要約 |
| 🟢 PDF自動要約 | PDFが添付されたら、呼ばれなくても要約 |
| 🟢 ルール記憶 | 「今後こうして」と言われたことを記録し、以後の回答で守る（訂正への反応も検知） |
| 🟢 事実台帳 | 「いま実際どうなっているか」を会話から記録。同じ主題の古い認識は自動で上書きされ、回答時に最優先の一次資料として引かれる |
| 🟢 用語辞書 | 固有名詞の誤表記を登録すると、以後の回答で決定論的に自動修正 |
| ⚪ 添付ファイル読解 | 画像・文書を読んで答える（Claude Code 選択時のみ） |
| ⚪ Web検索 | 社内ログに無いことをWebで調べて答える（Claude Code 選択時のみ） |
| ⚪ 会話の続きを覚える | 同じチャンネルのやりとりをセッションとして継続 |
| ⚪ スレッド返信 | 返信を元投稿のスレッドに入れ、チャンネルを流れにくくする |
| ⚪ 画像生成 | 依頼に応じて画像を生成（外部連携が必要 → [07](07-integrations.md)） |
| ⚪ 納期追跡の会話操作 | 追跡中のタスクを会話で完了・キャンセル・期日変更できる（期日を変えると声かけもやり直す） |

## 正直さの仕組み

このプロジェクトが一番大事にしている部分です。**すべて決定論的な検査**で、AIの自己申告に頼りません。

| 機能 | 説明 |
|---|---|
| 🟢 できたフリ検出 | 「登録しました」と言ったのに実際は実行されていない場合、機械的に検出して**同じ投稿内で訂正** |
| 🟢 失敗の正直化 | 実行したが失敗した場合、嘘の完了文を本文から消し、1行目に失敗を明示 |
| 🟢 実行証跡 | マーカー実行の結果（成功も失敗も）を `-#` 行で必ず投稿に残す |
| 🟢 断定の自動裏取り | 「〜で確定」と断定した内容を、投稿前に社内ログ検索で裏取り |
| 🌗 根拠なし断定の計測 | 検索ヒット0なのに断定した投稿を記録（シャドー計測） |
| 🟢 自信度の自己申告 | 確信の持てない回答には「🤔 自信度低め」の注記を自分で付ける |
| 🟢 空約束の検出 | 「認識を更新します」と言ったのに何も保存されていない場合も、できたフリとして検出する |

## 呼ばれなくても働く（観察ループ）

30分ごと（設定可）にチャンネルを見回り、気づいたことがあるときだけ発言します。
**1日の発言回数に上限**があり（既定3回）、深夜は休みます。
発言前に別AIによる**最終監査**を通すこともできます。すべて ⚪🌗 です。

### 仕事を進める

| 機能 | 説明 |
|---|---|
| 議事録TODO抽出・納期の声かけ | 議事録からTODOと決定事項を抜き出して追跡し、期日が近い担当者に声をかける。TODOは「作業が進むチャンネル」を推定して紐づけ、決定事項は言い直しの重複を保存時に弾く。超過の声かけから7日動きが無ければ「追跡を手放す」と一言添えて閉じる（会話で `A6 を open に` と言えば再開）。追跡の開始・期日の声かけ・手放しの投稿は種類ごとに止められる（止めても追跡と記録は続く） |
| 追跡タスクの統一ビュー | 議事録TODO（A）・宿題（H）・リマインダー（R）を `A6` `H27` `R57` のような番号で1つの一覧に。会話で「H27 を完了に」「A6 を 9/12 に」と頼める。管理画面の「データ → 追跡タスク」でも閲覧できる |
| 宿題の追跡 | 「〇〇やっときます」という発言を拾っておき、後日「あれどうなりました？」。**声かけの直前にその後の会話とリアクションを読み直し、人間だけで片付いていれば掘り返さない**。返事が無ければ数日後にもう一度だけ聞き、それでも動かなければ「流れた」と一言添えて手放す |
| 🌗 会話への自発介入（注意ループ） | 会話が途切れたチャンネルを読み、担当や結論が決まらないまま流れた話題を0〜10点で採点。閾値以上を**数時間寝かせてから**、発言直前にその後の会話を読み直し、人間だけで解決していれば黙って取り下げる。発言は8〜22時のみ・同じチャンネルには12時間あける・1日の上限あり |
| 見捨てられた質問を拾う | 24時間誰も答えていない質問に代わりに答える |
| 止まった話題の状況確認 | 動きが止まったチャンネルに「これどうなっていますか？」 |
| 決定の波及チェック | 新しい決定が入ったら、ぶつかる過去の決定・ずれるタスクの期日・ずれる定期リマインダーを横断で探し、直し方の案を出す。✅でそのまま反映（旧決定を上書き済みに・期日を直す・リマインダーは一時的な曜日変更や再開日まで含めてコードで計算して登録し直す。元の状態は自動でバックアップ）、❌で見送り。自動で直せないものは、案に返信で直し方を教えると対応し、その直し方は見本として残る |
| イベントの逆算スケジュール | 「イベントやります」を検知して、当日から逆算した準備計画案を出す |
| イベントの節目ウォッチ | 確定した計画の、自分の担当分野の節目が近づいたら知らせる |

### 自分を疑う（自己改善）

| 機能 | 説明 |
|---|---|
| 回答の自己採点 | 投稿した回答を後から採点して記録（投稿には影響しない） |
| 自己採点の蒸留 | 低スコア・👎・断定・できたフリ・差し止めの5系統から共通因子を週1で抽出し、「心がけ」として次回以降に注入。言い直しは同じ心がけとみなして連続週数を積み、3週続いた心がけは恒久ルールへの格上げを提案（✅で昇格） |
| 模範Q&Aのキュレーション | 決定台帳・事実台帳・固有名詞辞書から「時間が経っても答えが変わらない社内Q&A」の候補を作り、人が採用/不採用を決める（`python -m core.golden_curate`）。採用分は回帰テストの物差しになり（`python -m core.golden_eval`）、管理画面の「データ → 模範のQ&A」で状態を確認できる |
| その日の自己点検 | 夜に、その日の怪しい判断を自分で振り返る |
| 偏りの自己開示 | 「誰にはよく反応し、誰には反応していないか」を月次で自己申告 |
| 予測と答え合わせ | 月初に前月の自分の予測を答え合わせし、今月分を封印 |
| 人格と実態のズレ点検 | 人格定義と実際の発言のズレを点検して直し方を提案 |
| 人格チューニングの月次提案 | 行動データから設定の改善案と、使われていないスキルの棚卸し |
| 話し方のA/B実験 | プロンプトのA/B比較。差が出たときだけ採用を提案（自動採用しない） |
| 乗っ取り耐性の自主訓練 | 自分に悪意ある指示文を試し、乗っ取られないかを月次で自己テスト。報告するのは突破されたときだけ。突破は「点検で赤」として失敗と間違いの台帳に入り、1件で即起票される（`python -m core.verify_safety` で同じ点検を手動でも流せる） |
| 失敗と間違いの台帳 | ❌された提案とそのとき聞いた理由（返信で一言・任意）、自動ではやり切れなかったこと、ツールの失敗（設定オフや権限不足のような想定内のものは除く）、できたフリの検出、頼まれたけどできなかったことを1か所に貯める。同じ種類が3件たまると開発BOTへの改善の起票になる（❌は理由つきのものだけ数える）。乗っ取り訓練の突破・模範Q&Aの回答品質の急落（`core.golden_eval` で直近平均から大きく下がったとき）は1件で即起票。管理画面の「データ → 失敗と間違い」で読める |
| 満足度アンケート | 月1回、1問だけのアンケート |
| 四半期の目標宣言 | 前期の実績と今期の目標を自分で宣言 |

## ツールループ（回答の途中で社内データを引く・書く）

エージェントの設定 `tool_loop`（OFF / シャドー / 本番・既定はOFF）で有効化。回答中に
以下のツールを自分で呼び、結果を見てから本文を書く（書き込みの結果は -# 行で残る）。
Claude Code を選んでいるときだけ使えます。

| 種別 | ツール |
|---|---|
| 読む | search_messages（過去ログ全文検索）/ get_facts（事実台帳）/ get_decisions（決定台帳）/ list_reminders / list_tasks（A=議事録TODO・H=宿題・R=リマインダー）/ lookup_terms（固有名詞辞書）/ recall_lessons（自分の教訓） |
| 書く | save_fact・cancel_fact / save_rule・cancel_rule / add_reminder・cancel_reminder / shift_reminder（定期リマインダーの曜日・時刻を一時的または恒久的に変える。再開日もコードで計算）・reschedule_reminder（次回だけ動かす） / update_task（done・cancel・due・open）/ save_glossary・save_term / request_capability / save_lesson / set_proactive_quota（管理者） |

スキルを持たないツールは一覧に出ず、Bot 起点の発言とシャドー中は書き込みが見えない。
権限（本人・管理者・上限）はすべてサーバ側のコードで判定する。

| 段階 | 設定 | 挙動 |
|---|---|---|
| シャドー（有効化したときの既定） | `{"enabled": true, "shadow": true}` | 読み取りツールだけ。証拠行は本文に付けず活動ログに記録。やりとりは `state/toolloop/` に残る |
| 本番 | `{"enabled": true, "shadow": false}` | 書き込みもツールで実行し、結果の -# 行を本文に付ける。失敗は本文1行目で伝える。同種のマーカーは除去のみ |
| 注入削減 | `inject_search_hits` / `inject_facts` / `prompt_style` | 先に渡す関連メッセージ・事実台帳を減らし、必要なときにエージェントが引く。`python -m core.golden_eval` で A/B |

観察ループ（二次判定・放置質問の救出）にも読み取りツールが渡り、自己採点は
「実際に使ったツールと結果」を根拠として受け取る（検索して答えた事実を
「根拠のない断定」と誤採点しない）。
