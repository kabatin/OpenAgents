# 機能一覧

このシステムに入っている機能の全カタログです。
**ほとんどはダッシュボードのトグル1つでON/OFFできます。**

凡例:
- 🟢 = 既定でON
- ⚪ = 既定でOFF（画面から有効化）
- 🌗 = シャドー対応 — 有効にしても最初は**投稿せず記録だけ**する試運転モードで動かせます

---

## 聞けば答える（会話）

ホームチャンネルの発言や `@名前` の呼びかけに答える、基本の能力です。

| 機能 | 説明 |
|---|---|
| 🟢 過去ログ検索回答 | 全会話をSQLiteに記録し、質問されると**検索してから**引用リンク付きで答える。エージェント間で記憶は共有 |
| 🟢 会話の文脈理解 | 直前の会話を読み、「それ」「あの件」の指す先を補って答える |
| 🟢 リンク/ID参照 | メッセージリンクや素のIDを貼ると、その投稿の中身を読んで踏まえる |
| 🟢 リマインダー | 「明日9時に◯◯を知らせて」の自然文で登録。毎日・毎週・毎月末の繰り返し、チャンネル宛・ロール宛も可 |
| 🟢 YouTube要約 | URLが貼られたら字幕から要約 |
| 🟢 PDF自動要約 | PDFが添付されたら、呼ばれなくても要約 |
| 🟢 ルール記憶 | 「今後こうして」と言われたことを記録し、以後の回答で守る（訂正への反応も検知） |
| 🟢 事実台帳 | 「いま実際どうなっているか」を会話から記録。同じ主題の古い認識は自動で上書きされ、回答時に最優先の一次資料として引かれる |
| 🟢 用語辞書 | 固有名詞の誤表記を登録すると、以後の回答で決定論的に自動修正 |
| ⚪ 添付ファイル読解 | 画像・文書を読んで答える（Claude Code 選択時のみ） |
| ⚪ Web検索 | 社内ログに無いことをWebで調べて答える（Claude Code 選択時のみ） |
| ⚪ 会話の続きを覚える | 同じチャンネルのやりとりをセッションとして継続 |
| ⚪ スレッド返信 | 返信を元投稿のスレッドに入れ、チャンネルを流れにくくする |
| ⚪ 画像生成 | 依頼に応じて画像を生成（外部連携が必要 → [07](07-integrations.md)） |
| ⚪ 納期追跡の会話操作 | 追跡中のタスクを会話で完了・キャンセル・期日変更できる（期日を変えると声かけもやり直す） |

## 正直さの仕組み

このプロジェクトが一番大事にしている部分です。**すべて決定論的な検査**で、AIの自己申告に頼りません。

| 機能 | 説明 |
|---|---|
| 🟢 できたフリ検出 | 「登録しました」と言ったのに実際は実行されていない場合、機械的に検出して**同じ投稿内で訂正** |
| 🟢 失敗の正直化 | 実行したが失敗した場合、嘘の完了文を本文から消し、1行目に失敗を明示 |
| 🟢 実行証跡 | マーカー実行の結果（成功も失敗も）を `-#` 行で必ず投稿に残す |
| 🟢 断定の自動裏取り | 「〜で確定」と断定した内容を、投稿前に社内ログ検索で裏取り |
| 🌗 根拠なし断定の計測 | 検索ヒット0なのに断定した投稿を記録（シャドー計測） |
| 🟢 自信度の自己申告 | 確信の持てない回答には「🤔 自信度低め」の注記を自分で付ける |
| 🟢 空約束の検出 | 「認識を更新します」と言ったのに何も保存されていない場合も、できたフリとして検出する |

## 呼ばれなくても働く（観察ループ）

30分ごと（設定可）にチャンネルを見回り、気づいたことがあるときだけ発言します。
**1日の発言回数に上限**があり（既定3回）、深夜は休みます。
発言前に別AIによる**最終監査**を通すこともできます。すべて ⚪🌗 です。

### 仕事を進める

| 機能 | 説明 |
|---|---|
| 議事録TODO抽出・納期の声かけ | 議事録からTODOと決定事項を抜き出して追跡し、期日が近い担当者に声をかける |
| 宿題の追跡 | 「〇〇やっときます」という発言を拾っておき、後日「あれどうなりました？」 |
| 見捨てられた質問を拾う | 24時間誰も答えていない質問に代わりに答える |
| 止まった話題の状況確認 | 動きが止まったチャンネルに「これどうなっていますか？」 |
| 矛盾する過去の洗い出し | 新しい決定と矛盾する過去の記録を横断で探して知らせる（✅で旧決定を無効化） |
| イベントの逆算スケジュール | 「イベントやります」を検知して、当日から逆算した準備計画案を出す |
| イベントの節目ウォッチ | 確定した計画の、自分の担当分野の節目が近づいたら知らせる |

### 定期配信

| 機能 | 説明 |
|---|---|
| 朝のブリーフィング | 今日の期日・予定・重要な未読を毎朝1本 |
| 定例会議の事前パック | 定例の1時間前に、未完了タスク・直近の決定・前回議事録リンク |
| 週次レポート | 「今週こう動きました」を金曜夕方に1回 |
| 社内新聞 | 週1でタブロイド風の新聞を発行（見出し＋挿し絵） |
| 業界ニュースの巡回 | 指定キーワードのニュースを週1で最大3件 |
| 浦島さんへのあらすじ | 長く休んでいた人が戻ったら、不在中のあらすじを1回だけ |
| 御用聞き | 週1で「何かお手伝いできることはありますか？」 |

### 知識を育てる

| 機能 | 説明 |
|---|---|
| Wikiの自動更新 | 新しい決定が関係するページだけ編み直し、既存投稿を上書き（チャットを流さない） |
| 人物メモの蓄積 | よく発言する人の担当・口ぶりを静かに記録（投稿なし） |
| エピソード記憶 | 決定・完了・イベントを時系列に記録（投稿なし） |
| ルールの棚卸し | 貯まったルールの重複・時代遅れを週1で見直して無効化を提案 |

### 自分を疑う（自己改善）

| 機能 | 説明 |
|---|---|
| 回答の自己採点 | 投稿した回答を後から採点して記録（投稿には影響しない） |
| 自己採点の蒸留 | 低スコア・👎・断定・できたフリ・差し止めの5系統から共通因子を週1で抽出し、「心がけ」として次回以降に注入。3週続いた心がけは恒久ルールへの格上げを提案（✅で昇格） |
| その日の自己点検 | 夜に、その日の怪しい判断を自分で振り返る |
| 偏りの自己開示 | 「誰にはよく反応し、誰には反応していないか」を月次で自己申告 |
| 予測と答え合わせ | 月初に前月の自分の予測を答え合わせし、今月分を封印 |
| 人格と実態のズレ点検 | 人格定義と実際の発言のズレを点検して直し方を提案 |
| 人格チューニングの月次提案 | 行動データから設定の改善案と、使われていないスキルの棚卸し |
| 話し方のA/B実験 | プロンプトのA/B比較。差が出たときだけ採用を提案（自動採用しない） |
| 乗っ取り耐性の自主訓練 | 自分に悪意ある指示文を試し、乗っ取られないかを月次で自己テスト |
| 満足度アンケート | 月1回、1問だけのアンケート |
| 四半期の目標宣言 | 前期の実績と今期の目標を自分で宣言 |

### 組織として動く

| 機能 | 説明 |
|---|---|
| エージェント間の相談 | 専門外の質問を、担当の同僚AIにメンションで引き継ぐ（連続発言の上限で暴走防止） |
| 組織図の掲示 | 人間とAIの担当一覧を月次で掲示（編集上書きで流さない） |
| 欠員の発見と採用提案 | 「担当のいない仕事」を見つけて新AIの採用を提案。**管理者の👍で、チャンネル作成込みで自動採用** |
| 勉強会 | 個別に得た学びを他のAIへ広げる会を提案 |
| 自動化ネタの発掘 | 「毎回手でやっている作業」を見つけて自動化を提案（👍で開発起票へ） |
| 🌗 「その他」枠の観察実験 | 発言する類型の枠外で「同僚なら一言添える」と判断した場面を**投稿せず記録だけ**する。枠の絞り込みが妥当かをダッシュボードの「学びと実験」タブで人間が判断できる |

## 拡張のしくみ

| 機能 | 説明 |
|---|---|
| 外部連携（integrations/） | スプレッドシート・社内APIなどをフォルダ1つで追加（→ [07](07-integrations.md)） |
| プラグイン（core/tools/） | AIが自分で書ける小さな道具。`os`/`subprocess`/ネットワークは構文解析で禁止 |
| 性格テンプレート | 性格・口調・禁止事項をMarkdownで。ブラウザから編集、再起動不要で反映 |
| LLMの差し替え | Claude Code / Codex CLI / 自前のCLI（→ [04](04-llm-providers.md)） |
| プラットフォーム追加 | Slack等を `ChatPlatform` 実装で追加可能（→ [10](10-adding-platforms.md)） |

## 別プロセスのBOT（既定OFF）

| 機能 | 説明 |
|---|---|
| ⚪ 開発BOT | Discordで開発を指示 → 隔離環境で実装しテストを回す → **人間の👍で本番反映**。他BOTの死活監視・週次開発レポート付き |
| ⚪ 議事録BOT | ボイスチャンネルを録音 → 話者別に文字起こし → 議事録を自動投稿。話者名の名寄せ付き |

## 運用

| 機能 | 説明 |
|---|---|
| 🟢 スーパーバイザ | `python run.py` 1本で全BOTを起動・監視。クラッシュは指数バックオフで再起動、ハングは生存証明の鮮度で検出 |
| 🟢 管理ダッシュボード | セットアップウィザード・全設定のGUI・稼働監視・ログ閲覧・性格編集 |
| 🟢 ログ管理 | 自動ローテーション（20MB・3世代） |
| 🟢 自動起動 | mac（launchd）/ Windows（タスクスケジューラ）1コマンド登録 |
