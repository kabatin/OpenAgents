# Discord の Bot を作る

エージェントの「体」にあたる Bot を作って、あなたのサーバーに入れるまでの手順です。
**プログラミングの知識は要りません。** 10分ほどで終わります。

> セットアップ画面（`python start.py` で開くもの）にも同じ手順が出ます。
> 画面を見ながら進めるなら、そちらの方が楽です。この文書は、
> 手元で確認したいときや、うまくいかないときのために置いてあります。

---

## 1. アプリケーションを作る

1. <https://discord.com/developers/applications> を開きます
   （Discordのアカウントでログインします）
2. 右上の **New Application** を押します
3. 名前を入れます。これは管理用の名前なので、後で変えられます
   （例: `MyAgent`）
4. 規約に同意して **Create** を押します

## 2. Bot にする

1. 左のメニューから **Bot** を選びます
2. これで Bot ができています（新しいDiscordでは自動で作られます）

## 3. ⚠️ いちばん大事な設定

同じ **Bot** の画面を下にスクロールすると
**Privileged Gateway Intents** という欄があります。

次の**2つとも**オンにして、下の Save Changes を押してください。

- **MESSAGE CONTENT INTENT**
- **SERVER MEMBERS INTENT**

> **どちらを飛ばしても動きませんが、症状が違います**
>
> **MESSAGE CONTENT** が無いとき: Bot はオンラインになり、エラーも出ません。
> でも**発言の中身が空で届く**ので、何を話しかけても反応しません。
>
> **SERVER MEMBERS** が無いとき: **そもそも接続に失敗します**。
> ログに `PrivilegedIntentsRequired` が出ます。
>
> 「設定は合っているはずなのに動かない」の原因は、ほぼこの2つのどちらかです。

## 4. トークンを取る

同じ **Bot** の画面の上の方に **Token** の欄があります。

1. **Reset Token** を押します
2. 確認されるので進みます
3. 長い文字列が表示されます。**Copy** を押してコピーします

> **注意**
> - この文字列は**一度しか表示されません**。閉じてしまったら、もう一度
>   Reset Token を押せば新しいものが出ます（古い方は使えなくなります）
> - これは**パスワードと同じ**です。人に見せたり、GitHubに上げたりしないでください
> - **Client Secret とは別物です。** OAuth2 の画面にある方ではありません

## 5. サーバーに入れる

セットアップ画面でトークンを確かめると、**招待リンクが表示されます**。
それを押して、自分のサーバーを選ぶだけです。

手で作る場合は次のようにします。

1. 左のメニューから **OAuth2** → **URL Generator** を選びます
2. **SCOPES** で `bot` にチェックを入れます
3. **BOT PERMISSIONS** で次にチェックを入れます
   - View Channels（チャンネルを見る）
   - Send Messages（メッセージを送る）
   - Read Message History（履歴を読む）
   - Embed Links / Attach Files（リンクとファイル）
   - Add Reactions（リアクションを付ける）
   - Create Public Threads / Send Messages in Threads（スレッド）
4. 下に出てきたURLをコピーしてブラウザで開き、サーバーを選んで **認証** します

> **Administrator（管理者）にチェックを入れないでください。**
> 必要な権限だけを渡す方が安全です。上のものだけで全機能が動きます。

## 6. サーバーIDやチャンネルIDは？

**調べる必要はありません。** セットアップ画面が一覧で出すので、選ぶだけです。

（開発者モードを有効にして右クリックでIDをコピーする、という手順を
見かけたことがあるかもしれませんが、この仕組みでは不要です。）

---

## エージェントを増やすとき

**1つのトークンで複数の人格にはなれません。** 2体目を足すときは、
手順1からもう一度、別のアプリケーションを作ってください。
それぞれに MESSAGE CONTENT INTENT と SERVER MEMBERS INTENT の設定が必要です。

増やす操作は「全体設定」画面の **エージェントの増減** からできます。

---

## うまくいかないとき

### 「トークンが違います」と出る

- Client Secret を貼っていませんか（OAuth2 の画面のもの）。使うのは **Bot** の画面の Token です
- 前後に空白や改行が入っていませんか
- Reset Token を押した後、**古いトークンは使えなくなります**。最新のものを使ってください

### Botはオンラインなのに、話しかけても無反応

ほぼ確実に **MESSAGE CONTENT INTENT** が入っていません（手順3）。
（接続自体ができていないなら **SERVER MEMBERS INTENT** の方です）
オンにして保存し、`python run.py` を再起動してください。

### サーバーの一覧に自分のサーバーが出ない

Bot がまだそのサーバーに入っていません（手順5）。
招待リンクから入れてください。

### 「そのチャンネルへ投稿する権限がありません」と出る

そのチャンネルが非公開になっているか、Botのロールに送信権限がありません。
チャンネルの設定 → 権限 で、Botのロールに「メッセージを送信」を許可してください。
別の公開チャンネルを選んで試すと、切り分けが早いです。

### ログを見たい

```
state/logs/archivebot.log
```

「運用」画面からも読めます。
