# 使うAI（LLM）を選ぶ

エージェントが考えるのに使うAIは差し替えられます。
**ダッシュボードの「使うAI（LLM）」から選ぶのが簡単です**（インストール済みの
ものだけが選択肢に出ます）。ここでは設定ファイルの形と、選択による違いを説明します。

## 前提

このプロジェクトは **APIキーではなくコマンドラインのAIツール**を使います。
すでに契約しているサブスクリプションをそのまま使えるので、
トークン課金を別途気にしなくて済むのが理由です。

## 設定

```jsonc
"llm": {
  "provider": "claude",        // 使うツール
  "model": "claude-sonnet-5",  // モデル名（省略するとツールの既定）
  "timeout_sec": 180           // 何秒待つか
}
```

## 選べるもの

| provider | ツール | 入手先 |
|---|---|---|
| `claude` | Claude Code | <https://claude.com/claude-code> |
| `codex` | Codex CLI | <https://github.com/openai/codex> |
| 任意の名前 | 自分で指定したコマンド | 下記 |

## 機能の差（重要）

**ツールを使う機能は Claude Code 専用です。**

| 機能 | `claude` | それ以外 |
|---|:---:|:---:|
| 質問に答える（過去ログを検索して回答） | ○ | ○ |
| 会話の要約・議事録の整形 | ○ | ○ |
| 観察ループ（自発的な気づき・週次レポート等） | ○ | ○ |
| 性格・口調の反映 | ○ | ○ |
| **添付ファイルの読解**（画像・PDF） | ○ | × |
| **Web検索** | ○ | × |
| **開発BOTの自己改修** | ○ | × |
| **MCPサーバー連携** | ○ | × |
| **会話セッションの継続** | ○ | × |

他のツールにも似た機能はありますが、権限の渡し方も出力の形も違うため、
**動くふりをせず無効にしています**。他のプロバイダを選ぶと、
ダッシュボードに「このプロバイダでは○○が使えません」と表示され、
該当機能を呼ぼうとしたときも同じ理由でエラーになります
（黙って添付を読まずに答える、という事故を防ぐためです）。

## 自分のCLIを足す

「標準入力にプロンプトを流すと標準出力に本文が返る」形のコマンドなら、
コードを書かずに追加できます。

```jsonc
"llm": {
  "provider": "mycli",
  "model": "my-model-v2",
  "providers": {
    "mycli": {
      "label": "My CLI",              // 画面に出る名前
      "command": ["mycli", "--quiet", "--model", "{model}"],
      "bin": "mycli",                 // 実行ファイル名（省略時は command の先頭）
      "install": "https://example.com/mycli"   // 未導入時に案内するURL
    }
  }
}
```

- `{model}` は `llm.model` の値に置き換わります
- プロンプトは**標準入力**から渡されます。引数で受け取るCLIには対応していません
  （長い会話でコマンドライン長の上限に当たるため、標準入力で統一しています）
- 組み込みの `claude` / `codex` も、同じ書き方で上書きできます

### 動作確認

ダッシュボードの「応答テスト」を押すと、実際に一言返させて結果を表示します。
コマンドラインからも確認できます。

```bash
./venv/bin/python -c "
from core import config, llm
cfg = config.load()
print('使うAI :', llm.spec_for(cfg)['label'])
print('モデル :', llm.model_for(cfg))
print('制約   :', llm.describe_limits(cfg) or 'なし')
print('返事   :', llm.generate('こんにちはと一言だけ返して', cfg))
"
```

## うまくいかないとき

**「〜が見つかりません」と出る** — ツールがインストールされていないか、
PATH が通っていません。launchd やタスクスケジューラから起動すると
PATH が最小限になることがあるため、`~/.local/bin` `/usr/local/bin`
`/opt/homebrew/bin` も自動で探しますが、それ以外の場所に入れている場合は
`command` に絶対パスを書いてください。

**返事が遅い・途中で切れる** — `timeout_sec` を伸ばしてください。
Web検索や長い資料の読解を伴うと5分を超えることがあります。

**「出力が空でした」と出る** — ツール側でログインが切れている可能性があります。
そのツールを手で1回実行して、認証が通るか確かめてください。
