# エージェントを増やす

まず1体で試して、良さそうなら増やす——という順番をおすすめします。

## 先に知っておくこと

**1つのトークンで複数の人格にはなれません。** 2体目には**別のBotアカウント**が
必要です。Discord Developer Portal でもう1つ Application を作るところから始まります
（[01-discord-bot-setup.md](01-discord-bot-setup.md) の手順1〜5をもう一度）。

**MESSAGE CONTENT INTENT と SERVER MEMBERS INTENT の設定も、Botごとに必要です。** ここを忘れると、
その子だけ無反応になります。

## 手順

1. Developer Portal で新しい Application → Bot を作る
2. MESSAGE CONTENT INTENT と SERVER MEMBERS INTENT をオンにして保存
3. Reset Token でトークンをコピー
4. **同じサーバーに招待する**（招待リンクは新しい Application のものを使います）
5. ダッシュボードの「全体設定」→「エージェントの増減」→「エージェントを追加」
6. トークンを貼って接続テスト → ID・表示名・チャンネル・性格を選ぶ
7. 「適用」ボタンで再起動

## 決めること

### ID

`agent2` のような英小文字の識別子です。**あとで変えない方が無難**です
（DBの記録がこのIDで紐づいているため、変えると過去の記録と繋がらなくなります）。

### ホームチャンネル

そのエージェントの自室です。**別々のチャンネルにするのがおすすめ**です。
同じチャンネルに複数置くと、誰が答えるかが分かりにくくなります。

### 呼ばれた時だけ答えるか

2体目以降は既定で **`require_mention: true`**（名指しされたときだけ答える）に
なります。全員がホームチャンネルの全発言に反応すると、チャットが賑やかすぎるためです。

変えたい場合は「エージェント」画面の「呼ばれた時だけ答える」で切り替えられます。

### 性格

テンプレートから選ぶか、既存のものをコピーして書き換えます。
**役割ごとに分けると効果があります** — 例えば設計の相談役は「寡黙な分析役」、
雑談も拾ってほしい子は「元気な後輩」。

## 記録担当（archiver）について

会話をDBに記録するのは**ちょうど1体だけ**です。追加したエージェントは
自動的に記録担当ではなくなります（二重記録を防ぐため）。

**記録は共有されます。** どのエージェントも同じDBを検索するので、
別のチャンネルでの会話も踏まえて答えられます。

## エージェント同士の会話

登録されたエージェントは、お互いをメンションして相談できます。
延々と続かないよう、**Bot発言が連続 `max_bot_chain` 回に達すると自動で止まります**
（既定4回。人間が発言するとリセット）。

## 消すとき

「全体設定」→「エージェントの増減」→「削除」。
**記録担当は削除できません**（先に別のエージェントを担当にする必要があります）。

設定から消えるだけで、**過去の会話記録は残ります**。検索の材料としてはそのまま使えます。
